# Retail-Data-Analysis-SQL
Retail data analysis project using SQL Server and SSMS to analyze customer, transaction, product, sales, revenue and return data.

## Project Overview

This project focuses on analyzing retail point-of-sale (POS)
data using Microsoft SQL Server.

The objective is to understand customer behavior, transactions,
product categories, revenue, sales channels, and returns through
SQL-based data analysis.

## Business Context

A retail store wants to understand customer behavior using
point-of-sale transaction data.

## Dataset

The project contains three tables:

1. Customer
2. Transactions
3. Product Category

The analysis covers:

- Transaction channel analysis
- Customer gender distribution
- Customer city analysis
- Product sub-category analysis
- Quantity analysis
- Revenue analysis
- Customer transaction frequency
- Sales and returns
- Store-type performance
- Average revenue
- Category and subcategory performance
